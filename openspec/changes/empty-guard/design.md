## Context

Форма добавления новой карточки `NewCardForm` принимает ввод пользователя и отправляет его на сервер без предварительной валидации. Из-за этого создаются пустые элементы.

## Goals / Non-Goals

**Goals:**
- Добавить валидацию строки (удаление пробелов через `.trim()`).
- Заблокировать отправку формы, если поле пустое.
- Сделать кнопку «Добавить» неактивной (`disabled`) при пустом вводе.

**Non-Goals:**
- Изменение структуры данных на сервере или в API.

## Decisions

Внутри компонента `NewCardForm` использовать проверку `!text.trim()`. Если она истинна, кнопке добавления присваивается атрибут `disabled`, а функция отправки формы прерывает свое выполнение (`return`), предотвращая создание пустой карточки.
